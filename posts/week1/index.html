Week 1 · Exercise 1.8

Marvel Comics hyperlink network

For this first exercise, we asked a simple question: how do Wikipedia article-to-article hyperlinks connect characters in the Marvel Comics universe? We used the frozen Week-1 network released for the course, which contains 303 Marvel characters and the directed links between their Wikipedia pages.

Nodes 303
Directed edges 1,784
Undirected edges 1,434
Isolates 17

What data we used

The dataset was downloaded from the course data page and loaded with pandas and NetworkX. The node file includes the character identifiers, names, and Wikipedia metadata, while the edge file records a directed link from one page to another wherever the source article links to the target article. The course page specifically warns that 17 characters have no links in either direction, so we preserved all 303 node ids before adding edges. This matters because building the graph only from the edge list would silently drop isolates.

What we did

We built a directed NetworkX graph from the node list and the edge list, then computed the in-degree and out-degree of each character. We also converted the network to an undirected graph to study connectivity and the largest connected component. Finally, we generated plots of the degree distributions on linear and log-log axes, and a visualization of the directed network itself.

What surprised us

One surprising feature is that the graph contains 17 isolated characters, even though the edge list has 1,784 links. This means network structure is not a single fully connected web: a small but non-zero set of characters are disconnected from the rest of the hyperlink graph. Another notable point is that the degree distributions are highly skewed: a few characters attract many incoming hyperlinks, while most characters have far fewer. In other words, the network is dominated by a handful of central hubs rather than being uniformly connected.

Why in-degree and out-degree can differ

In this Wikipedia network, a directed edge means “page A contains a link to page B.” That makes in-degree a count of how often a character is referenced by other pages, while out-degree measures how many links a character's page makes to others. These are not the same quantity, because pages are not equally likely to be cited or to cite others. A central hero like Spider-Man can be linked to by many pages, while another character may cite many different names but not be cited as often in return.

Analysis code

The scripts and generated figures used in this post are stored in the repository, and the analysis is run directly from the project folder to keep the workflow reproducible. The code adds every node before adding edge data so that isolated nodes are preserved, which is essential here because 17 characters are disconnected.
